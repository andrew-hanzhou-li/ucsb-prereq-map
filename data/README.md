# data

Inputs and in-between results of the [pipeline](../pipeline). The website itself loads from `site/data/`, not from here.

- **Downloaded from the catalog:** `raw_courses.json`, `raw_programs.json`, `catalog_prereqs.json`
- **Parsed prerequisites:** `prereqs.json`
- **Typed in by hand:** `overrides.json`, `program_overrides.json`, `offering_overrides.json`, `ap_credit.json`
- **Requirements for each program:** `majors/`
